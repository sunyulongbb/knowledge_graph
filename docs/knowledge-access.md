# 知识访问权限

右侧知识编辑框右上角提供「公开 / 私有」选择，新知识默认公开。保存时由服务端记录当前登录用户的 ID、用户名和最近更新者 ID，客户端不能指定创建者。

- 公开：所有人可阅读，创建者与获准维护者可编辑。
- 私有：创建者与获准维护者可阅读、编辑。
- 创建者可以修改访问级别、删除知识、审批申请和移除维护者；维护者不能执行这些管理操作。
- 系统管理员可以读取全部知识；对已有创建者的知识，编辑和删除仍按创建者、获准维护者的权限执行。没有创建者记录的历史知识由管理员管理。

登录用户可以在公开知识详情页底部申请维护，创建者在同一位置批准或拒绝。批准后，申请人出现在维护者名单中。转为私有时保留已批准的维护者；移除维护者后立即撤销其权限。

启动服务时增量添加权限字段和维护申请表，不替换原有数据。历史知识保持公开，未记录创建者的知识由系统管理员管理，不猜测历史归属。

读取权限覆盖知识列表、搜索、统计、关系图、属性、Wiki 和知识附件。API 禁用缓存，关系图本地缓存按账号隔离，退出或切换账号时重新加载页面。

验证：`bun test`。权限测试使用内存 SQLite，覆盖公开与私有可见性、服务器归属记录、并发账号隔离、关系引用与快照过滤、表格排序，以及申请、审批、撤销和越权修改。
