# 分类导入格式

文件必须是 UTF-8 编码的 JSON，最大 2 MB。

根对象字段：

- `version`：固定为 `1`。
- `classes`：非空分类数组。

分类字段：

- `id`：可选，分类 ID。导出文件会包含此字段；导入时同一项目中 ID 匹配的分类会保留 ID，避免知识关联失效。若 ID 已被其他项目占用，则会生成新 ID。
- `name`：必填，非空字符串。同一父分类下以名称匹配已有分类。
- `description`：可选，分类说明。
- `color`：可选，`#RRGGBB` 格式。
- `image`：可选，图片地址或 `null`。
- `tags`：可选，非空字符串数组。
- `children`：可选，子分类数组，最多 32 层。

一次最多导入 1000 个分类。导入是增量操作：同级同名分类更新明确提供的字段，新分类追加，未出现在文件中的分类保持不变。任何一项校验或写入失败时整份文件回滚。

## 按 ID 更新已有分类

先导出分类 JSON，保留 `id`，修改名称、描述、颜色、图片或标签后重新导入。同一应用中优先按 ID 更新，即使改名也不会创建重复分类，知识关联保持不变。`children` 的嵌套位置决定父分类；未提供的字段、未出现在文件中的分类保持不变。

```json
{"version":1,"classes":[{"id":"class/source","name":"新的分类名称","tags":["新标签"]}]}
```

不带 ID 时按同级名称匹配；ID 未匹配时仍会尝试匹配同级名称，否则新增。其他应用的数据不会被覆盖。
