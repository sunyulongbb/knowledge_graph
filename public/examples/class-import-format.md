# 分类导入格式

文件必须是 UTF-8 编码的 JSON，最大 2 MB。

根对象字段：

- `version`：固定为 `1`。
- `classes`：非空分类数组。

分类字段：

- `name`：必填，非空字符串。同一父分类下以名称匹配已有分类。
- `description`：可选，分类说明。
- `color`：可选，`#RRGGBB` 格式。
- `image`：可选，图片地址或 `null`。
- `tags`：可选，非空字符串数组。
- `children`：可选，子分类数组，最多 32 层。

一次最多导入 1000 个分类。导入是增量操作：同级同名分类更新明确提供的字段，新分类追加，未出现在文件中的分类保持不变。任何一项校验或写入失败时整份文件回滚。
